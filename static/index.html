1 Upload BOQ / Quotation Files Tab: 📤 Upload BOQ
What you do:
  • Drag & drop your Excel files (.xls / .xlsx)
  • Click 🔍 Scan First to preview contents before saving
  • Click 📤 Upload to Catalog to save permanently
  • Delete any file using the 🗑 button if needed
What happens behind the scenes:
  • System reads every sheet in the Excel file
  • Auto-detects header row and column names (Product, Price, Brand, GST…)
  • Detects whether price is in INR or USD from column name
  • Saves all products into the SQLite database
  • Duplicate files are rejected automatically
📌 Supported columns auto-detected: Product Name, Description, Model No, Brand, Specification, HSN Code, Price/PC INR, Price/PC USD, GST%
2 Type Your Requirements Tab: ✨ Generate Quote
What you do:
  • Enter customer / hotel name
  • Select which catalog(s) to search from (or leave blank for all)
  • Type requirements in plain English:
    "We need 100 irons, 50 iron boards and 200 hand towels"
  • Click ✨ Generate Quotation
What happens behind the scenes:
  • Keywords extracted from your prompt (numbers and stop-words ignored)
  • Database searched for matching products using keyword relevance scoring
  • Top 30 most relevant products sent to Groq AI (LLaMA 3.3 70B)
  • AI decides which products to include and what quantities
  • AI response validated — only products existing in catalog are kept
  • Prices, brand, model overridden with exact catalog values
📌 AI Model: LLaMA 3.3 70B via Groq (free tier). Token limit: 12,000 per minute. If hit, wait 60 seconds and retry.
3 Review & Edit the Result Tab: 📋 Result
What you do:
  • Review line items — product, qty, price, GST
  • Edit any value directly in the table (qty, price, GST%)
  • Remove unwanted rows with ✕
  • Click 💾 Save Edits to save changes
  • Click ⬇ Download XLS to export
Currency handling:
  • INR items — shown with ₹, included in grand total
  • USD items — auto-converted to INR at live exchange rate
  • USD column shows original $ price alongside INR equivalent
  • Totals shown separately for INR and USD sections
  • Combined grand total shown at bottom
📌 All edits are saved to the database. The XLS is generated from your uploaded template (preserving original formatting) or a default format if no template.
4 Give Feedback — Train the AI Tab: 📋 Result → Feedback section
What you do:
  • Click 👍 Good — quote is correct, approve it
  • Click 👎 Not Good — describe what was wrong or missing
What happens behind the scenes:
  • Good → Quote status set to "approved", moved to Repository
  • Not Good → Feedback text saved to database
  • Next generation includes recent feedback in the AI prompt
  • AI learns to avoid repeating past mistakes
📌 The last 30 feedback entries are always sent to the AI so it continuously improves its suggestions.
5 Repository — Approved Quotes Tab: 🗄 Repository
What you can do:
  • View all approved quotations
  • Re-download any past quote as XLS
  • View draft quotes (generated but not yet approved)
  • Manually approve a draft with ✓ Approve button
How it helps future quotes:
  • Approved quotes serve as training examples for the AI
  • Similar prompts in future will give similar results
  • All quotes stored with reference number, client name, date
📌 Reference numbers follow format: SMI-YYYYMM-XXXX (e.g. SMI-202606-0001)

Technology Stack

🐍
FastAPI
Python backend — handles all API calls, file parsing, DB operations
🤖
Groq AI
LLaMA 3.3 70B model — understands requirements and matches products
🗄
SQLite
Local database — stores catalog, quotations, feedback
📊
Pandas + openpyxl
Reads .xls/.xlsx files, detects columns, extracts all sheets
💱
Frankfurter API
Live USD→INR exchange rate (free, no API key needed)
🌐
Vanilla JS
Frontend — no frameworks, fast and lightweight
